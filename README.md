# SilkRail

Платформа мониторинга железнодорожной инфраструктуры: интерактивная карта станций, предприятий, камер и переездов, карточка станции (15 разделов), панель управления, аналитика вагонных весов, видеонаблюдение. Интерфейс на UZ / RU / EN, светлая и тёмная темы.

**Стек:** FastAPI + SQLAlchemy 2 (SQLite по умолчанию, PostgreSQL в Docker) · React 19 + Vite + Ant Design 5 + Leaflet + ECharts + hls.js + three.js · i18next.

## Быстрый старт (локально)

```bash
# 1. Бэкенд
cd backend
pip install -r requirements.txt
python -m app.osm_import           # скачивает реальные ж/д пути и станции из OpenStreetMap (~30–60 сек, нужен интернет)
python -m app.seed                 # создаёт БД; станции/переезды/предупреждения ставятся точно на пути
uvicorn app.main:app --port 8000

# 2. Фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                        # http://localhost:5173 (проксирует /api на :8000)
```

Вход: **admin / Admin123** (superadmin) или **viewer / Viewer123**.

## Данные

**Геометрия путей и станции** — из OpenStreetMap (© OpenStreetMap contributors, лицензия ODbL): ~380 станций и остановочных пунктов с кодами ЕСР, пути main/branch (без подъездных и промышленных), признак электрификации. `app/osm_import.py` сливает сегменты, упрощает (допуск ~25 м) и привязывает каждую станцию к ближайшей точке пути (станции дальше 1,5 км от путей и метро отбрасываются). Результат кэшируется в `data/osm_stations.json` и `data/osm_rails.json` — повторно скачивать не нужно. Если интернета нет, seed использует упрощённую синтетическую сеть.

Импорт берёт станции, остановочные пункты и парки (узлы и площадные объекты), пути main/branch, а также подъездные/промышленные пути, если они длиннее 2 км или на них стоит станция. Станции, которые не удалось привязать (дальше 1,5 км от пути), выводятся в консоль.

**Недостающие станции** можно добавить прямо на карте: «Obyektlar» → «Stansiya qo'shish» → клик по карте (роль admin/superadmin). Точка автоматически привязывается к ближайшему пути и сохраняется в `data/custom_stations.json`, поэтому переживает повторный `seed`.

**Редактирование карты** (только admin/superadmin): «Obyektlar» → «Режим редактирования» — метки станций, предприятий, камер, переездов и предупреждений можно перетаскивать, клик открывает форму переименования. Там же «Добавить метку» — собственные метки (значок, цвет, описание). Правки станций и метки дублируются в `data/map_edits.json` и повторно применяются при `seed`.

**Карточка станции** (правки только admin/superadmin): фото станции (кнопка «Добавить фото», несколько фото листаются), «Редактировать» у общих сведений, контактов и кодов операций, вкладка 360° — загрузка своих сферических панорам 2:1 (JPG/PNG/WebP до 80 МБ). Файлы лежат в `backend/static/uploads/stations/`, правки дублируются в `data/map_edits.json` и переживают `seed`. Погода — реальная, из Open-Meteo (без ключа, кэш 10 мин); без интернета показывается сезонная оценка с пометкой.

**Сотрудники и пути станции** (правки только admin/superadmin): вкладка «Сотрудники» — добавление/редактирование/удаление, штатные единицы; статистика, образование и возрастные группы считаются из введённых данных. Вкладки «Сотрудники» и «Тех. описание» — кнопки «Шаблон Excel» (файл с текущими данными, выпадающими списками и инструкцией, привязан к станции) и «Загрузить Excel»: файл проверяется построчно, при ошибках показываются строка и столбец и ничего не меняется, иначе раздел станции заменяется данными файла. Данные дублируются в `data/station_records.json` и возвращаются после `seed`. Демо-сотрудников и пути seed создаёт только с `SEED_DEMO_STAFF=1`.

**Пользователи** (`/users`, только admin/superadmin): создание, редактирование, удаление; для каждого пользователя можно ограничить доступные разделы (Карта / Панель / Аналитика / Камеры). Ограничение проверяется и на сервере (403 на API закрытых разделов).

Все данные синтетические (`backend/app/seed.py`), координаты узловых станций приблизительные. Чтобы подключить реальные источники, замените сид или добавьте импорт в те же таблицы (`backend/app/models.py`). Потоки камер в сиде — публичные тестовые HLS; замените `stream_url` на свои.
